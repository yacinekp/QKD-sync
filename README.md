This is an attempt to experiment with new synchronization mechanism for existing quantum key distribution protocols such as BB84.
# How to use 
This solution can be used locally between two terminals as well as between two virtual or physical machines.

1. In order to establish the communication, the communicating parties must be connected to the same network.
